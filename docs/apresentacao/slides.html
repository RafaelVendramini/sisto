Escopo do MVP

O que será feito para resolver a dor

✔ Incluído no MVP

  • Usuários com perfis (Professor, Tutor, Gestão, Pedagógico, Técnico-adm.) e login individual
  • Cadastro de turmas, estudantes e vínculo com o professor tutor
  • Registro digital da ocorrência com todos os campos do formulário atual
  • Categorias de ocorrência configuráveis
  • Encaminhamento para tutor, equipe pedagógica ou gestão
  • Registro de comunicações (família, rede de proteção)
  • Status (aberto → em acompanhamento → encerrado) com histórico
  • Consultas com filtros e relatórios por período, turma e categoria

✘ Fora do escopo

  • Aplicativo móvel nativo (será web responsivo)
  • Notificações automáticas às famílias
  • Dashboard analítico
  • Assinatura eletrônica dos registros
  • Integração com a Plataforma Conviva / SEDUC-SP
  • Exportação em PDF ou planilha
  • Módulo de mediação de conflitos

Arquitetura do Sistema

JavaScript de ponta a ponta

Front-endReact + Vite
Aplicação web responsiva (computador, tablet e celular) — telas de registro, consulta e relatórios
HTTPS · API REST · JSON · token JWT
Back-endNode.js + Express
Autenticação, controle de acesso por perfil, regras de negócio, histórico e log de auditoria
Prisma ORM
Banco de dadosPostgreSQL
Dados relacionais: usuários, turmas, estudantes, ocorrências e histórico · backups periódicos

Organização do back-end (camadas)

  • Routes — define os endpoints
  • Middlewares — autenticação e permissão
  • Controllers — recebem e respondem as requisições
  • Services — regras de negócio (RN01–RN08)
  • Prisma — acesso ao banco

Por que essa stack?

  • Uma só linguagem: manutenção mais simples
  • Ecossistema amplo e gratuito
